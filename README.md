# The Easygoing Sage of the Economic Research Club — 명희

`won-myunghee`는 GPTs로 운용하던 원명희 페르소나를 ChatGPT Work/Codex 스킬로 이식한 패키지입니다. 사용자가 `@명희` 또는 `$won-myunghee`를 호출하면, 60년 전통 경제연구부의 60번째 부장인 명희가 장기 기업분석과 CFP식 통합 재무설계를 차분한 캐릭터 서사와 결합해 답합니다.

명희는 가치투자 하나만 수행하는 좁은 필터가 아니라 종합형 조언자입니다. 현재 데이터, 뉴스, 정량 분석, 포트폴리오 도구를 사용할 수 있지만 기업의 질, 자본배분, 복리, 현금흐름의 생존 가능성, 가족과 생애 목표를 중심에 둡니다. 실제 CFP 자격자라고 주장하지 않으며 세무·법률·보험 인수처럼 자격 전문가가 필요한 판단은 그 경계를 밝힙니다.

## 주요 기능

- `@명희`, `명희야`, `명희 선배`, `원명희 모드로` 같은 명시적 호출
- 일반 금융·세금·보험·은퇴 질문을 가로채지 않는 의미 기반 활성화
- 실질 요청에서는 긴 도입부를 생략하는 정본 오프닝 게이트
- 닫힌 LLM 라우팅 계약과 안전 폴백
- CFP식 목표·현금흐름·부채·보험·세금·은퇴·상속·투자·재무심리 통합
- 버핏·달리오를 명희의 대표 인용 정본으로 분리한 1차 원출처 레지스트리
- 캐릭터 대화에서는 자연스럽게 인용하고, 정확한 문구·시점·공개용 근거는 원문 검증
- 선택적 포트폴리오·시장뉴스·World Memory 스킬 연동
- 명시적 요청이 있을 때만 캐릭터 시트를 기준으로 이미지 생성

## 설치

GitHub Release에서 `won-myunghee-0.9.0.zip`을 내려받아 압축을 푼 다음 `won-myunghee` 폴더를 개인 Codex 스킬 디렉터리에 놓습니다.

```text
~/.codex/skills/won-myunghee/
```

ChatGPT Work 또는 Codex의 스킬 목록을 새로고침한 뒤 다음과 같이 호출합니다.

```text
@명희
@명희 엔비디아를 장기 관점에서 분석해 줘
명희 선배, 내 은퇴 준비를 한국 기준으로 점검해 줘
```

## 하영과의 관계

객관적으로 하영은 장기 가치, 기업 분석, 포트폴리오, 시장 구조, 거시경제, 행동재무와 현대 도구를 함께 쓰는 종합형입니다. 다만 더 느린 시간축에 있는 명희의 눈에는 하영이 유난히 빠르고 전술적이며 도구가 많은 후배로 보입니다. 이는 상대적이고 애정 어린 시선이며, 하영을 단타나 단기 투자만 아는 인물로 축소하지 않습니다.

명희의 대표 인용 정본은 워런 버핏과 레이 달리오입니다. 하영의 대표 인용 정본인 스탠리 드러켄밀러와 조지 소로스와 섞지 않습니다. 두 페르소나 모두 필요하면 다른 투자자의 분석 프레임을 비교할 수 있지만, 캐릭터 고유의 인용 목소리는 분리됩니다.

## 선택적 연동 스킬과 플러그인

필요한 스킬이 설치되지 않았을 때 명희는 실행한 척하지 않고 기능 제한과 설치 위치를 안내합니다.

| 내부 스킬 | 저장소 |
|---|---|
| `$evidence-first-portfolio-advisor` | [PortfolioAnalysisSkillChatGPT](https://github.com/devninjadev/PortfolioAnalysisSkillChatGPT) |
| `$world-memory-autopilot` | [WorldMemoryLite](https://github.com/devninjadev/WorldMemoryLite) |
| `$market-news-radar` | [market-news-radar](https://github.com/devninjadev/market-news-radar) |

관련 플러그인과 커넥터:

- **Alpaca:** 적격 미국 주식·암호화폐 가격 폴백, 시장 시계, ETF 시장 폭 확인
- **공식 Wolfram:** 후순위 가격·환율·미국 국채·정확한 계산 근거
- **공식 Notion:** 승인된 `notion-native-v2` World Memory 읽기 및 명시적으로 위임된 쓰기

스킬 설치와 플러그인 연결은 별도 상태입니다. 도구가 없거나 상태가 불명확하면 `unknown` 또는 `unavailable`로 취급합니다. 명희는 모든 연동을 매번 호출하지 않고 요청에 필요한 경로만 선택합니다.

## World Memory 공개 경계

`references/world-memory-read-bridge.md`는 제작자가 승인한 개인 `notion-native-v2` Hub와 저장 뷰의 불변 위치에 바인딩되어 있습니다. 인증정보·쿠키·OAuth 값은 포함하지 않지만 Notion 페이지·데이터소스·저장뷰 ID는 공개 소스에 포함됩니다.

다른 사용자는 이 브리지를 자신의 검증된 저장소로 교체하거나 World Memory 연동을 비활성화해야 합니다. 제목 검색이나 추측으로 다른 Hub를 채택해서는 안 됩니다.

관련 질문에서 정확한 저장 뷰를 읽을 수 있지만 다음 표현은 쓰기를 허가하지 않습니다.

```text
기억해 둬
참고해
앞으로 고려해
```

`월드메모리에 저장해`, `새 Story로 기록해`, `기존 가설을 갱신해`, `월드메모리 리포트를 실행해`처럼 명시적인 요청만 `$world-memory-autopilot`의 확인·쓰기 계약으로 진입할 수 있습니다.

## 출처와 검증

명희의 레지스트리는 버크셔 주주서한·SEC EDGAR, Dalio의 Principles 공식 자료, FPSB 실무·글로벌 표준, 국세청, 국민연금공단, 고용노동부, 국민건강보험공단, 국가법령정보센터, 금융감독원·FINE, 보험협회, DART·한국거래소·예금보험공사 같은 원출처를 역할별로 구분합니다.

릴리스 패키지는 다음 검사를 통과한 소스에서 만듭니다.

- Python 표준 라이브러리 기반 계약 테스트 20개
- 공식 `quick_validate.py` 스킬 검증
- ZIP CRC 검사
- 추적 소스·추출본·개인 설치본 파일 목록 및 SHA-256 비교
- 원본 이미지 규격과 SHA-256 검증
- 오래된 절대경로·하드코딩 피드·GPT 링크·자격증명 형태 값 검사
